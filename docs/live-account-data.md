# 老何实盘数据接入

## 数据源与刷新

- `liveAccount` 云函数读取服务端绑定账户的 `investment_ledger_strategies`、`investment_ledger_records`。
- 来源配置存放在 `investment_ledger_accounts/laohe-live-account-source`；仅管理员可绑定自己的账户，已绑定其他账户时拒绝覆盖。
- 访问者不能通过请求参数选择 ownerId。登录且存在用户资料的用户目前均可读取展示结果。
- 前端进入页面、恢复可见/焦点以及可见时每 60 秒重新读取。无需导出、复制或重新发布账本记录。
- 重新读取不代表账本每分钟产生新数据。页面说明为“通常于交易日收盘后半小时内更新”，具体以记录日期为准；没有新增定时生成记录的任务。
- 失败时保留上次结果并明确提示同步失败；不回退演示数据。

## 服务端脱敏

返回字段采用显式白名单：账户日期/净值/日收益率/回撤、策略展示标识/名称/分类/颜色/归档状态/净值曲线，以及日期对应的持仓比例和实际记录日期。

不返回本金、资产金额、出入金、备注、改名原因、ownerId、用户信息或原始数据库 ID。策略展示标识由单向散列生成，不使用原始策略 ID。历史改名只用于对应日期的名称展示，不下发原始历史对象。

`snapshots` 是独立的持仓数据模块。以后限制会员访问时，应在云函数鉴权后决定是否返回此字段，并同步调整前端空态；仅在前端隐藏不能构成权限控制。当前未启用会员限制。

## 策略公开说明

- 管理中心（admin）的“实盘说明”选项卡按策略编辑纯文本，仅管理员可访问，最多 1000 字，空文本表示清空说明。实盘展示页不再提供编辑入口。
- `saveStrategyDescription` 在服务端校验管理员身份及脱敏策略标识，使用事务按策略更新 `investment_ledger_accounts/laohe-live-account-descriptions` 的 `descriptions` 映射。
- `getOverview` 仅追加当前展示策略的公开 `description` 字段，不读取账本备注作为说明。前端以文本方式展示，禁止 HTML 渲染。该字段是管理员明确编写的公开内容。
- `access.test.js` 覆盖越权、非法标识/长度、存储读取、清空和私密字段不外泄。

## 计算与完整性

遵循投资账本当前计算口径：首条记录净值为 1，后续日收益率为 `(当日期末金额 - 前次金额 - 当日现金流) / 前次金额`。账户按记录日汇总，缺少更新的策略沿用最近余额；归档策略历史仍参与汇总。前次余额为零时按账本规则处理，不用出入金制造收益。

持仓按日期回溯，沿用此前余额时返回实际记录日。现金仅展示账本中实际存在的策略记录，不推算额外现金。比例显示四舍五入到一位小数，合计可能有尾差。

一次读取完整历史，达到读取上限则报错，不展示截断结果。`projection.test.js` 验证现金流、缺失日期、归档、回撤和脱敏；`access.test.js` 验证登录、管理员绑定和越权参数。

## 部署与验证

- 云函数源文件：`functions/liveAccount/`（仓库既有规则忽略 functions，须按项目惯例另行备份/部署）。
- 部署：`tcb functions:deploy liveAccount`；只部署这一新增云函数。
- 测试：`node --test functions/liveAccount/projection.test.js functions/liveAccount/access.test.js`。
- 前端：`src/services/liveAccount.ts`、`src/views/live-account.vue`。
- 本次已部署云函数并绑定当前登录管理员账户；本地前端已接入。公网前端需按现有发布流程发布后才使用新接口。
