# 微盘走势数据提供要求（简版）

适用范围：更新网站微盘策略的历史走势曲线。以下是供人工整理、转换的数据交付模板，不是网站现成的上传接口格式。

## 1. 最简单的交付方式

提供一份 Excel 或 CSV，每个交易日一行，包含下面两列即可：

| 日期 | 策略净值 |
| --- | --- |
| 2026-11-02 | 1.000000 |
| 2026-11-03 | 1.012000 |
| 2026-11-04 | 1.006940 |

以上仅为虚构示例，请替换为实际数据。策略净值指同一口径下每日收盘的累计净值，不是当天涨跌幅；可以从 1 起算，也可以提供连续的策略指数点位，但整份文件必须口径一致。

如有沪深300同期收盘点位，可增加“沪深300收盘点位”一列。只更新已有日期的策略走势时，可以复用已有基准；新增日期若现有基准未覆盖，需要补齐同期基准数据才能完整更新两条曲线。

可复制到表格软件的 CSV 示例：

```csv
日期,策略净值
2026-11-02,1.000000
2026-11-03,1.012000
2026-11-04,1.006940
```

## 2. 数据要求

- 日期使用 YYYY-MM-DD，按日期升序排列，同一天不能重复。
- 每个交易日提供一个收盘值，非交易日不必填写；缺失交易日请说明，不要自行填零。
- 净值必须是大于零的数值，尽量保留原始精度。空仓日也应有净值记录，按策略实际收益填写。
- 如果只是追加近期数据，请同时提供至少一个新旧数据重叠的交易日，便于核对和衔接。若历史规则或计算口径改变，建议提供完整历史，并说明需要替换的日期范围。
- 实盘账户数据需要剔除入金、出金对净值的影响，不能直接把账户总资产当成策略净值。

## 3. 随文件附上这几句话

```text
策略名称/版本：
数据来源：回测 / 模拟 / 实盘（填写一种，并说明来源）
数据区间：____年__月__日至____年__月__日
更新方式：追加近期 / 替换历史（写明范围）
收益口径：是否包含手续费、滑点、分红；是否包含1月和4月空仓规则
数值类型：累计净值 / 策略指数点位 / 累计收益率 / 每日收益率
```

如果只能导出收益率，也可以提供，但请写清是“每日收益率”还是“累计收益率”，以及单位。例如：1.2% = 小数 0.012，不能混用。累计收益率还需注明统一起算日期；每日收益率转换净值时需明确首日收益对应的前一日基准。

## 4. 不需要提供的内容

仅更新历史走势，不需要逐笔成交记录、每日股票明细或账户密码。日收益、年化收益、最大回撤等可以由连续净值计算。

如果还要同步更新当前持仓或盘中实时净值，则另需核对持仓日期、股票代码、权重及收盘基准；这属于另一项更新，不能仅靠历史净值完成。

## 5. 项目当前的数据对应关系

当前微盘页面通过 getMicroCapStrategyData 云函数读取 micro_cap_strategy_base/latest。核心走势字段为 dateList（日期）、strategyData（策略数值）、hs300（沪深300基准）；dailyReturn 可由相邻策略数值计算。上述表格需要核对、转换后再写入，不应直接运行旧导入脚本覆盖线上数据。

本说明根据本地代码检查编写，未查询线上最新日期，也未修改或发布线上数据。
