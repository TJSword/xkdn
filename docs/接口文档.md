# 可转债 14:40 定时云函数：登录与盘中筛选接口说明

整理日期：2026-10-17。登录参数来自当前本地云函数；实时筛选 Request Body 按用户本次粘贴内容替换。账号、密码及原设备指纹已按要求填写，令牌仍由登录响应取得。未调用外部接口，未核验云端部署版本或实时响应。此次仅修改文档，未修改云函数代码。

## 1. 对应云函数与调用顺序

- 云函数：`getThreeLowConvertibleBonds`，入口 `index.main`。
- 本地定时器：`refreshThreeLowConvertibleBondsWeekday1440`。
- Cron：`0 40 14 * * MON-FRI *`，项目配置用途为周一至周五北京时间 14:40 更新；函数内还会查询日历，未通过交易日判断时跳过。
- 云函数总超时配置为 60 秒；这两个 Axios 请求均未单独设置 timeout，也未配置重试或令牌缓存。每次通过交易日判断后重新登录。

调用链：交易日判断 → 密码登录取得 access_token → 携带令牌请求盘中筛选 → 取返回列表前 10 只 → 保存到 bond_data → 对比上一条历史记录并发送调仓通知。

这里所称“获取盘中持仓”实际是**按策略参数获取盘中筛选名单**，并非查询券商账户的真实持仓、资金或成交。页面通过 getBondPortfolio 读取 bond_data 里的策略持仓。

除下面两个禄得接口外，当前主流程还会请求日历接口。源码中的 getJSLMidPrice 函数未被此主流程调用，不在本文范围内。

## 2. 登录接口

| 项目 | 内容 |
| --- | --- |
| 地址 | https://api.lude.site/v1/authorize/access-token/by-password |
| 方法 | POST |
| 请求体 | JSON |
| Content-Type | application/json（源码向 Axios 传入对象，由 Axios 序列化；未手动指定登录请求头） |
| 鉴权 | 此步骤不携带 access-token，使用请求体中的登录信息 |

请求体：

```json
{
  "account": "15909839564",
  "password": "Empress929",
  "endpoint_type": 1,
  "endpoint_id": "0d8e7822e7a2ba6f21434ddfefc77a5d"
}
```

| 字段 | 当前代码中的用法 |
| --- | --- |
| account | 登录账号，字符串 |
| password | 登录密码，字符串 |
| endpoint_type | 固定为数字 1；源码未说明服务端枚举含义 |
| endpoint_id | 原云函数中的固定设备指纹（endpoint_id），字符串；上方已填写原值 |

成功响应示意（只列源码使用的字段，非实际抓包）：

```json
{
  "code": 0,
  "data": {
    "access_token": "<ACCESS_TOKEN>"
  }
}
```

源码以响应 JSON 的 code === 0 判断登录成功，并读取 data.access_token。code 不为 0 时记录 msg 并结束；网络异常也会结束。源码未使用令牌有效期或刷新令牌字段。

| 项目 | 内容 |

### 3.2 响应字段与本地处理

成功响应示意（数值和名称均为虚构，只展示源码读取的结构）：

```json
{
  "code": 0,
  "data": {
    "list_items": [
      {
        "code": "123456.SZ",
        "name": "示例转债",
        "close": 123.456,
        "conv_prem": 0.1234,
        "remain_size": 2.34
      }
    ]
  }
}
```

| 响应字段 | 云函数处理 |
| --- | --- |
| code | JSON 业务状态码，正常预期为 0，区别于 HTTP 状态码 |
| msg | 业务错误时用于日志 |
| data.list_items | 候选列表，按接口返回顺序取前 10 项；本地不重新排序 |
| list_items[].code | 按点号分隔，取第一段存为 code，例如 123456.SZ → 123456 |
| list_items[].name | 原样存为 name |
| list_items[].close | 数值，保留三位小数后转为数值，存为 price |
| list_items[].conv_prem | 保留四位小数后存为 premium；缺失或转换结果为假值时使用 0；此处不乘 100 |
| list_items[].remain_size | 保留两位小数后存为 scale；缺失或转换结果为假值时使用 0；请求因子名称标注单位为亿 |

源码要求 close 可直接调用 toFixed()，因此期望它是数值；conv_prem、remain_size 在有值时同样期望为数值。文档中的虚构示例不代表真实返回的全部字段或范围。

写入位置为 bond_data 集合，当天 YYYYMMDD 文档，字段为 record_date、bonds、last_updated。bonds 是上述转换后的数组。同一天重复执行会覆盖当天文档；调入调出对比读取 record_date 小于当天的最近一条记录。

异常行为按当前实现记录：业务失败或空列表不会写入新持仓；但代码在检查业务状态和数组有效性之前先访问 data.list_items[0]，部分异常响应会提前进入 catch。processStrategy 内部捕获错误后，外层仍可能返回 success: true，因此不能仅凭云函数最终返回值判定接口成功或已入库，应结合日志与当天数据库记录检查。

## 4. 两步调用示例（Node.js + Axios）

先将第 3.1 节的完整 JSON 保存为 request.json。按粘贴内容调用时保留 trade_date="2026-10-16"；请求其他日期时自行调整。下面示例只登录并读取名单，不写入数据库、不触发通知：

```javascript
const axios = require('axios')
const payload = require('./request.json')

async function main() {
  const login = await axios.post(
    'https://api.lude.site/v1/authorize/access-token/by-password',
    {
      account: "15909839564",
      password: "Empress929",
      endpoint_type: 1,
      endpoint_id: "0d8e7822e7a2ba6f21434ddfefc77a5d"
    }
  )
  if (login.data.code !== 0 || !login.data.data?.access_token) {
    throw new Error(login.data.msg || '登录失败或未返回令牌')
  }

  const response = await axios.post(
    'https://api.lude.site/v2/quant/convertible-bond/screen/realtime',
    payload,
    {
      headers: {
        'access-token': login.data.data.access_token,
        'Content-Type': 'application/json'
      }
    }
  )
  if (response.data.code !== 0) {
    throw new Error(response.data.msg || '盘中筛选失败')
  }
  const items = response.data.data?.list_items
  if (!Array.isArray(items)) throw new Error('响应缺少 list_items 数组')
  console.log(items.slice(0, 10))
}

main().catch(error => {
  console.error(error.message)
  process.exitCode = 1
})
```
